# دفتر التقييم الرقمي — Flutter Offline

نسخة بداية عملية لتحويل نظام التقييم إلى تطبيق Android مستقل، بقاعدة SQLite محلية، دون خادم أو حساب مركزي.

## المنجز في هذه المرحلة

- واجهة عربية RTL.
- قاعدة SQLite محلية تُنشأ تلقائيًا داخل مساحة التطبيق الخاصة.
- إضافة التلميذ وتعديل بياناته وحذفه.
- قائمة تلاميذ مع البحث والتصفية حسب القسم.
- بطاقة التلميذ.
- تقييم أكاديمي وسلوكي بثلاثة مستويات: غير مكتسب (0)، في طريق الاكتساب (1)، مكتسب (2)، مع دعم حالة «لم يقيّم».
- حساب نسب التقييم الأكاديمي والسلوكي والعام.
- حفظ لقطات التقييم بحسب الفترة والسنة الدراسية.
- استيراد JSON من صيغة `students_data.json` القديمة ذات المفاتيح بأسماء التلاميذ، أو من نسخة هذا التطبيق.
- الاحتفاظ بالسجل الأصلي والحقول غير المعروفة داخل `legacy_json` عند الترحيل، وعدم حذف سجل التقييمات التاريخي.
- تصدير نسخة احتياطية JSON ومشاركتها من الهاتف.

## غير منجز بعد — لا تعتبره متاحًا في هذه النسخة

- استيراد Excel/CSV المباشر.
- تقارير PDF عربية وExcel.
- التقييم الجماعي للقسم.
- إدارة المناهج والمهارات من الواجهة.
- التحليل التربوي الذكي. هذا يحتاج اتصالًا اختياريًا بمزوّد خارجي، ويجب ألا تُرسل إليه بيانات تعريفية للتلاميذ.
- اختبار APK على جهاز Android فعلي.

## التشغيل والبناء

يتطلب Flutter SDK حديثًا وAndroid SDK (أو بيئة بناء Android مناسبة). مجلد منصة Android غير مولّد في هذه الحزمة؛ أنشئ ملفات المنصة مرة واحدة بالأمر الأول.

```bash
flutter create --platforms=android --org dz.edu.daftar .
flutter pub get
flutter analyze
flutter test
flutter build apk --release
```

الناتج المتوقع بعد نجاح البناء:

`build/app/outputs/flutter-apk/app-release.apk`

## استيراد بيانات المشروع القديم

من داخل التطبيق: الصفحة الرئيسية ← «استيراد بيانات قديمة» ← اختر ملف `students_data.json`.

الصيغة القديمة المتوقعة هي قاموس مفاتيحه أسماء التلاميذ، ولكل سجل `info` و`evaluations` و`history` أو `assessment_history`. المحوّل يتعامل مع `history` و`assessment_history` ويحفظ السجل الأصلي كاملًا ضمن بيانات الترحيل.

**تنبيه قبل الاستيراد:** خذ نسخة من ملف JSON الأصلي واحتفظ بها كما هي. لا تُرسل ملف بيانات تلاميذ حقيقيًا إلى أي خدمة عامة أو تشاركه علنًا.

## بنية البيانات

جدول `students` يحتوي على الحقول الأساسية، وتُحفظ التقييمات وسجل اللقطات والحقول الأصلية الإضافية كـ JSON داخل SQLite لتقليل مخاطر إسقاط بنية قديمة غير معروفة. قاعدة البيانات في مجلد التطبيق الخاص، ولا يمكن للتطبيقات الأخرى قراءتها مباشرة.

## بناء APK عبر GitHub Actions

أُرفق مسار عمل يدويًا في `.github/workflows/build-apk.yml`. بعد رفع المشروع إلى مستودع GitHub، افتح تبويب Actions وشغّل `Build Android APK`، ثم نزّل ملف APK من Artifacts. هذه آلية بناء، وليست نشرًا تلقائيًا.

## سياسة النسخ الاحتياطي

التصدير ينشئ JSON قابلًا للمشاركة. قبل حذف التطبيق أو إعادة ضبط الهاتف، أنشئ نسخة احتياطية وانقلها إلى مكان آمن. لا توجد مزامنة سحابية في هذا التصميم الأولي.
